## 🛠️ Local Setup & Running

### 1. Main HTML Version
Simply open `index.html` in any web browser, or serve it using a local server:

```bash
npx serve .
```

### 2. React Version (`react-portfolio`)

Navigate to the React project directory, install dependencies, and start the development server:

```bash
cd react-portfolio
npm install
npm run dev
```
